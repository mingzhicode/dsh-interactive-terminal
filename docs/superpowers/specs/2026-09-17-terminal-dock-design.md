# 内嵌单终端界面

## 范围

按照用户提供的折叠、展开截图调整 `dsh-interactive-terminal` Web 界面。采用已选定的方案 1：每个对话仍独占一个 PTY，不提供多标签页、标签计数、新增或关闭标签按钮。四个工具、严格排队、人工输入协议及 SIGKILL 行为不变。此前发现的多行输入提前释放队列、排队重置遇到退出失败等问题不在此次 UI 修改范围内，也不因本次修改视为解决。

## 官方接入

将插件从 `shell.overlay` 移到官方 `conversation.input.dock` 列表插槽，沿用 effect 管理注册与资源释放。已核对安装的 `@deepseek-ai/dsh-client-ui-conversation@0.1.0-rc.8` 公共声明：该插槽为会话作用域，提供输入框上方的独立全宽行。通过官方传入的会话数据确定当前终端，不查询或改写 Harness 内部 DOM，不扩展 PTY seam。同步声明所需公共客户端依赖及打包元数据。

## 展示与操作

终端在消息输入卡片上方随正常布局排列，与输入卡片同宽，不固定悬浮或遮挡输入框。折叠状态采用浅色圆角细边框，左侧为可访问的展开箭头和终端标题，右侧为设置按钮。标题不硬编码截图中的 `publishall`，也不复制截图中的 shell 提示符。

展开状态保留同一标题栏，下方为紧凑的连接、控制权和排队状态区域，以及白底、深色正文的真实 xterm 终端。保留 ANSI 颜色，输出和提示符来自实际 PTY。终端区域限制视口高度，内容可以滚动；仅调整浏览器显示高度及字号，不调用 PTY resize、FitAddon 或 stty。折叠只隐藏显示区域，不结束 shell 或释放输入占用。

设置按钮展开内联操作区，收纳现有重连、清屏、字号调整和重置操作；重置仍需明确确认。结束人工输入仍沿用现有动作、可用性和占用释放语义，不把截图里的停止图标实现为新增杀进程动作。不添加没有既定语义的图钉按钮。只读、移动端限制、断线提示、输入限额和错误提示继续可见且有效。

切换对话时不向旧对话发送新输入，卸载时按现有机制清理浏览器资源。按钮具有名称、焦点样式及展开状态，设置和重置确认可用键盘操作。截图作为布局参考，不要求修改聊天输入框、模型选择、会话统计或安装 shell 美化组件。

## 验收

先为官方插槽注册、折叠保活、设置显隐和重置确认补充失败测试，再实现最小界面改动。运行受影响的客户端测试、类型检查和浏览器构建；使用实际 Harness Web 页面检查展开与折叠布局、输入框无遮挡、终端输入和窄屏显示，并保留新截图。测试报告区分本次 UI 验证与已有未解决的失败用例，不声称整个插件已通过最终验收。同步独立插件 README，不修改 Harness 实现，不自动 commit，不发布 npm 包。
